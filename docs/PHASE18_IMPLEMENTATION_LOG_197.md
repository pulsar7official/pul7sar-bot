## Change Set 197 — Visual Critic Provenance Binding

### Added

1. `engine/intelligence/visual_brain_critic_provenance.py`
   - Adds `VisualCriticProvenanceGate` and a structured receipt.
   - Replays the canonical Visual Brain batch identity.
   - Binds critic evidence to candidate number, concept, request, seed, handoff payload SHA, provider/model, `$0-local` result, exact PNG path, and exact PNG SHA-256.
   - Records SHA-256 of manifest, generation result, critic evidence, and PNG.
   - Delegates the visual decision to the existing `VisualCriticGate`; it does not weaken or replace the critic thresholds.
   - Rejects repository path escape.
   - Always keeps human review required, Golden approval false, and publication readiness false.

2. `tools/phase18_verify_visual_brain_critic_provenance.py`
   - CPU-only CLI for replaying and writing the provenance receipt.
   - Returns a non-zero result when the visual critic rejects the candidate.
   - Does not run FLUX, mutate a queue, use a paid API, or grant publication authority.

3. `tests/test_phase18_visual_brain_critic_provenance.py`
   - Accepts premium/safe critic evidence only when it is bound to the exact generated bytes.
   - Rejects PNG tampering after evidence creation.
   - Rejects candidate/seed identity drift.
   - Proves hard visual failures remain rejected and non-publishable.
   - Rejects evidence paths outside the repository root.

4. `docs/PHASE18_CHANGESET_197_VISUAL_CRITIC_PROVENANCE_BINDING.md`
   - Full architecture/safety documentation for the change.

5. `docs/PHASE18_IMPLEMENTATION_LOG_197.md`
   - This implementation ledger entry.
