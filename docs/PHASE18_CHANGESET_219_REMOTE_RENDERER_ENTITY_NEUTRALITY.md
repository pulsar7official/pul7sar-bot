# Phase 18 Change Set 219 — Remote Renderer Entity Neutrality Lock

## Purpose

Keep the public ZeroGPU renderer comparison useful as a visual research lane without allowing it to encode an unverified real club, venue, or color-coded entity identity into the renderer prompt.

The remote benchmark remains strictly non-canonical. It may compare renderer quality, but it cannot become Golden evidence, Semantic approval, or publication authority.

## Problem closed

The existing transfer renderer benchmark was already platform-name-free and identity-obscured, but it still contained identifiable real-world cues such as:

- `North London` venue/location language;
- `deep navy and clean white` destination identity coding; and
- `cool sky-blue` source identity coding.

Those cues were inappropriate for an anonymous renderer-quality study because they can steer the image toward recognizable clubs or venues without verified entity assets or canonical fact/identity binding.

## Implemented changes

### `tools/phase18_remote_renderer_compare.py`

- raised the benchmark contract to `pul7sar-phase18-remote-renderer-benchmark-v3`;
- added the required marker `no identifiable real club or venue cues`;
- added fail-closed detection for the known club/location/color-coded identity cues that existed in this benchmark;
- retained the existing PUL7SAR/PULSAR name-leak rejection;
- added explicit evidence fields:
  - `entity_neutral_benchmark=true`;
  - `verified_identity_asset_used=false`;
  - `verified_venue_asset_used=false`;
- kept all remote-study authority closed.

### `benchmarks/phase18/savinho_transfer_renderer_benchmark_prompt.txt`

- removed `North London`;
- removed navy/white destination club-color coding;
- removed sky-blue source club-color coding;
- replaced them with generic destination/source visual hierarchy;
- added the explicit entity-neutrality marker.

### `tests/test_phase18_remote_renderer_benchmark.py`

Added regression coverage for:
- the canonical prompt being entity-neutral;
- real club/location cue rejection;
- color-coded entity cue rejection;
- required entity-neutrality marker rejection when removed;
- explicit remote-study authority closure.

## Canonical gates preserved

No canonical policy, model, quality threshold, or publication gate changed.

The following remain fail-closed:
- Fact Lock;
- Entity/Identity Verification;
- Sentiment/Neutrality and respectful loser treatment;
- canonical `$0-local` execution policy;
- Generated Text / Branding / Exact Facts / Entity Marks / Exact Sport Geometry exclusions;
- canonical model/runtime evidence;
- Semantic and Layer Ownership gates;
- byte-bound Visual Critic hard failures;
- explicit Human Review;
- Golden quality floor 8.5 and elite target 9.0+;
- Exact Brand Integrity;
- Typography Integrity; and
- SemanticPublicationGate.

Remote benchmark outputs remain:
- `$0-remote-zerogpu-study`;
- engineering-only;
- not canonical-Golden eligible;
- not Semantic-approved;
- not Golden-approved; and
- not publication-ready.
