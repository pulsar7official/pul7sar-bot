# PUL7SAR BRAND GUIDELINES

Version: 2.0 — Phase 18 Dynamic Brand System

This document supersedes the old context-blind accent rule for Phase 18 visual production.

PUL7SAR is a premium global sports-media identity. The brand structure must remain recognizable and deterministic, while the contextual accent may respond to the verified hero of the story.

---

## Brand character

PUL7SAR must feel:
- premium,
- confident,
- athletic,
- modern,
- dynamic,
- minimal,
- intelligent.

Avoid clickbait, visual clutter, cheap effects, random decorations and generative logo imitation.

---

## Core identity rule

The PUL7SAR brand is **not generated by the image model**.

Brand geometry and typography belong to the deterministic composition layer.

The distinctive contextual accent applies to:
- the number **7**,
- the **pulse** element.

Context may change the accent color; it must not redesign, stretch, rotate, distort or regenerate the brand structure.

---

## Default accent state

**PUL7SAR Red**

HEX: `#E10600`

This is the default state for the **7 + pulse**.

Use the default red when:
- the story is general,
- there is no single clear hero,
- two or more entities have equal visual priority,
- identity/hero confidence is below threshold,
- verified entity palette evidence is unavailable,
- the contextual color would fail readability/contrast policy.

---

## Contextual hero accent

When Story Intelligence establishes one unambiguous verified hero, the 7 + pulse may adopt a verified color from that hero's entity palette.

Required conditions:
- hero is unambiguous,
- hero confidence >= 0.85,
- palette evidence is explicit and verified,
- palette confidence >= 0.80.

The system must never guess an entity color from a name, model memory or a generated image.

In a club-v-club or athlete-v-athlete story without a clear editorial hero, use PUL7SAR Red rather than choosing a side arbitrarily.

---

## Entity colors versus PUL7SAR identity

Entity color is a contextual accent, not a replacement identity.

The final image should still read as PUL7SAR through:
- stable brand geometry,
- consistent typography,
- layout rhythm,
- visual hierarchy,
- premium editorial treatment,
- deterministic 7 + pulse placement.

Official club/team/competition marks remain exact verified assets. They must not be recolored or regenerated.

---

## Typography

Typography must remain deterministic and readable. Generative models may not render the headline, score, statistics, dates, footer, PUL7SAR wordmark or other exact text.

Headlines should be short, strong, professional and never misleading.

---

## Visual style

Preferred generative responsibilities:
- lighting,
- atmospheric depth,
- non-factual environment texture,
- crowd/environment mood,
- cinematic separation.

Responsibilities reserved for deterministic/verified layers:
- sport geometry,
- real-person identity when exact identity matters,
- scores/statistics/dates,
- club/team/competition marks,
- typography,
- PUL7SAR branding.

---

## Layout hierarchy

Priority is story-dependent, but the normal hierarchy is:
1. story hero / decisive visual meaning,
2. concise editorial headline or exact data monument,
3. supporting information,
4. contextual entity marks when required,
5. PUL7SAR branding and footer.

Branding must be recognizable but must not compete with the story hero.

---

## Production rule

A visual is not approved because a PNG exists.

Final approval requires:
- verified editorial facts,
- correct identity handling,
- correct dynamic brand decision,
- deterministic geometry where required,
- no generated PUL7SAR branding,
- no generated exact text/data,
- layer QA pass,
- semantic and Golden visual-quality pass.

## Brand rule

If the design could belong to any generic sports page, it is not finished.

If the image model has invented the PUL7SAR brand, the visual is rejected.

If contextual color weakens recognition or cannot be verified, return to PUL7SAR Red.
