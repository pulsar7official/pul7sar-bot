## Change Set 131 — First-PNG Hybrid Handoff

### Problem found

The genuine GPU smoke path and Golden Hybrid v5 QA path had one remaining orchestration split. Candidate 1 could be generated by `tools/phase18_first_png.py` and pass the first-PNG provenance postflight, but the existing Hybrid v5 semantic/composition consumer reads `output/phase18_colab/latest.json`. Without a canonical bridge, the same proven PNG was not immediately consumable by the Hybrid v5 path.

This was a workflow gap, not a reason to weaken semantic or publication gates and not a reason to generate another FLUX image.
