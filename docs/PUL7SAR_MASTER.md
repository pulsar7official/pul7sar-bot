# PUL7SAR MASTER DOCUMENT

Version: 1.0

This document defines the identity, philosophy, standards, and long-term direction of the PUL7SAR project.

Every contributor, developer, AI assistant, or future team member must follow this document.

---

# Mission

Build the world's most recognizable AI-powered sports media platform.

The platform must combine:

- Speed
- Accuracy
- Premium Design
- Automation
- Scalability
- Strong Brand Identity

PUL7SAR is not a Telegram bot.

It is a complete sports media ecosystem.

---

# Long-Term Vision

PUL7SAR will become a unified content platform capable of producing and distributing sports content automatically across multiple platforms from one central engine.

Future supported platforms include:

- Telegram
- Facebook
- Instagram
- X (Twitter)
- TikTok
- YouTube
- Website
- Mobile Application

All systems must be designed with this future in mind.

---

# Core Principles

## 1. Quality over Quantity

Publishing fewer high-quality posts is better than publishing many average posts.

---

## 2. Brand Consistency

Every post must instantly look like PUL7SAR.

Typography, spacing, colors, composition, and lighting must always follow one visual identity.

---

## 3. Automation First

Manual work should be minimized.

The system should automate:

- News collection
- News filtering
- AI rewriting
- Graphic generation
- Publishing
- Scheduling

---

## 4. Scalability

Every new feature must support future growth.

Never build temporary solutions.

---

## 5. Clean Architecture

The codebase must remain modular.

Each module has one responsibility.

Avoid coupling.

Avoid duplicated logic.

---

## 6. Reliability

The production system should continue working even if a new experimental feature fails.

Stable code is more valuable than clever code.

# Brand Personality

PUL7SAR should always feel:

Professional

Confident

Fast

Modern

Premium

Global

Never sensational.

Never clickbait.

Never visually noisy.

---

# Editorial Style

Headlines should be:

Short

Direct

Powerful

Easy to read

Professional

The first sentence should communicate the entire story.

Avoid unnecessary wording.

---

# Visual Standards

The visual identity must prioritize:

Dark backgrounds

Premium lighting

Strong typography

Minimal distractions

Consistent spacing

High contrast

Professional composition

Every generated card should be recognizable without reading the logo.

---

# Engineering Standards

Code should always be:

Readable

Reusable

Testable

Documented

Modular

Configuration-driven

Never hardcode business logic.

---

# AI Collaboration Rules

AI assistants are implementation partners.

They do not define the project direction.

Project direction is defined only by the official documentation.

Whenever AI recommendations conflict with this document, this document takes priority.

---

# Success Definition

PUL7SAR succeeds when:

People recognize the design before reading the logo.

Content is trusted.

Publishing is automated.

Adding a new platform requires minimal effort.

The brand becomes globally recognizable.
