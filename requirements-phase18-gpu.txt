# Optional dependencies for real Phase 18 local/free-GPU visual proof execution.
# PyTorch is intentionally not pinned/installed here because CUDA wheels depend on
# the execution environment (Colab/self-hosted GPU). The runtime gate verifies it.
# Diffusers 0.39.0+ exposes the FLUX.2 API family used by the Golden runner.
# Qwen2.5-VL is kept on the verified Transformers 4.x public API line. A blind
# major-version upgrade is not allowed in the Golden runtime because it can change
# multimodal import behavior independently of our code.
#
# Colab currently ships Pillow 11.x. Upgrading Pillow in-place to 12.x in a live
# notebook can leave an incoherent PIL package/module state (for example an
# ImageDraw/ImageText import looking for PIL._typing._Ink from a different
# installed generation). Keep Pillow on the verified 11.x line for Phase 18 so
# the one-command path does not damage the runtime before Qwen readiness runs.

accelerate
